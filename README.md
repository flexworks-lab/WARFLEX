# PROJECT STRIKE

A fast, browser-based first-person shooter built with Three.js.

## Features

- First-person mouse look with pointer lock
- WASD movement, sprinting, and jumping
- Hitscan rifle with 30-round magazines
- Reloading and reserve ammo
- Headshots and hitmarkers
- Enemy waves with escalating health/speed
- Simple enemy attack AI
- Score + kill tracking
- Arena cover and collision
- Tracer and hit particle effects
- Game over + redeploy loop
- Static-host friendly: no backend required

## Controls

- WASD — move
- Shift — sprint
- Space — jump
- Mouse — aim
- Left click — fire
- R — reload
- Esc — pause / release mouse
